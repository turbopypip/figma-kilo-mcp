# Проверка Figma Kilo MCP

Дата: 19 октября 2026. Исполнитель: Codex, self-review без отдельных агентов.

## Среда и результаты

- macOS / Darwin 24.6.0, arm64, Apple M1, 8 ГиБ RAM.
- Node.js 20.12.2, npm 10.5.0.
- MCP SDK server/client 2.3.1; зависимости закреплены в package-lock.json.
- Kilo CLI 7.8.12 запущен через npm exec; `kilo mcp list` с созданной конфигурацией вернул **figma connected**. Глобальные настройки Kilo не изменялись.
- `npm run check`: успешно, проверены сервер и Figma plugin typings.
- `npm test`: **13/13 успешно**.
- `npm audit --omit=dev`: 0 известных уязвимостей на момент запуска.

## Что проверено автоматически

Тест MCP запускает отдельный процесс собранного сервера и официальный MCP-клиент. Собранный плагин `plugin/code.js` выполняется с подменённым Figma API и соединяется с сервером через настоящий WebSocket.

Проверены обнаружение четырёх инструментов, ошибки схемы входа, отсутствие плагина, чтение выделения и контекста, MCP image с PNG, экспорт SVG на диск, частичные ошибки пакета и завершение процесса с освобождением порта. Отдельные тесты проверяют:

- правильный/неправильный секрет, отказ второму плагину, переподключение;
- busy, отмену, таймаут и закрытие соединения;
- конфликт порта, некорректный JSON и превышение размера WebSocket-сообщения;
- изменения макета без кеша, пустое выделение, удалённые узлы;
- ограничения дерева, текста, больших свойств и сложности экспорта;
- текстовые диапазоны, Auto Layout, недоступный главный компонент;
- PNG-масштаб, ограничение размера файлов, декодирование больших base64;
- отсутствие traversal/перезаписи, пути с пробелами и кириллицей, подмену каталога симлинком на macOS;
- код интерфейса плагина: pairing, пересылку запросов, очистку поля секрета и отклонение сообщений не от parent.

При self-review исправлена потенциальная проблема проверки больших base64: повторяющееся регулярное выражение заменено простой проверкой алфавита и проверкой канонического кодирования, добавлен регрессионный тест на 2 МиБ. Сверены остановка сервера, обработка отмены и аннотации инструмента экспорта, который записывает локальные файлы.

## Измеренные ресурсы сервера

Команда: `npm run measure`. Отдельный процесс сервера; тестовый макет: 2 узла, frame 4000×2000, PNG подменён маленьким изображением 1×1 (68 байт). Фактический расчёт масштаба — 0.512. Это измерение транспортного/серверного пути, **не производительности реального рендеринга Figma**.

| Этап | Длительность | CPU относительно одного ядра | RSS в конце |
| --- | ---: | ---: | ---: |
| Простой | 60.02 с | 0.135% | 25.98 МиБ |
| Серия 1: 10 контекстов + 10 PNG | 47.37 мс | 55.27% | 39.66 МиБ |
| Серия 2: 10 контекстов + 10 PNG | 9.58 мс | 62.07% | 38.67 МиБ |
| Серия 3: 10 контекстов + 10 PNG | 7.80 мс | 52.19% | 39.23 МиБ |

Накопительный peak RSS процесса: 63.86 МиБ. CPU измеряется через `process.cpuUsage`, память через `process.memoryUsage` и `process.resourceUsage`. Короткие нагрузочные интервалы имеют заметную погрешность. Три серии не демонстрируют непрерывного роста RSS, но недостаточны для вывода об отсутствии долгосрочных утечек. В простой нет периодических вызовов к плагину. Замер не включает процессы Kilo, Figma или тестового клиента. Исходные данные текущего запуска сохранены в `artifacts/resources-mock.json`.

## Что ещё не подтверждено

В этой среде не установлен Figma Desktop и нет Windows. Поэтому не выполнены:

- импорт manifest, проверка сетевого CSP и реального UI внутри Figma;
- вход в нужный аккаунт и чтение настоящего фрейма;
- получение контекста/PNG/ассетов агентом Kilo из настоящей Figma;
- измерение CPU/RAM и поведения путей на Windows;
- отдельное измерение нагрузки плагина на процесс Figma.

Добавленная CI-матрица Windows/macOS/Linux ещё не запускалась на удалённом CI. Эти пункты нельзя считать пройденными по результатам тестов с заглушками.

Для завершения приёмки на целевом ПК: выполнить инструкции README, проверить экран через Kilo, затем закрыть Kilo и запустить `npm run measure -- --real`. Сохранить отчёт `artifacts/resources-real.json`, размеры/число узлов выбранного настоящего фрейма, результат экспорта ассетов и показатели отдельной нагрузки Figma из средств мониторинга Windows.
