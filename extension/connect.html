Перед запросом

Передай агенту ссылку Copy link to selection из подключённого файла либо выбери слой в Figma. Мост сам открывает Properties, раскрывает и прокручивает Layers. Интерфейс Figma должен быть на английском. Контекст содержит только данные, доступные в панели; неполнота отмечается явно.

Экспорт активирует Figma. PNG использует буфер обмена и заменяет его. SVG получается через Export, включая ZIP с одной иконкой. Во время запроса не меняй выделение и не копируй другие данные. Расширение не читает прежнее содержимое буфера.

Это экспериментальный адаптер. Доступ к платному Dev Mode не нужен; запрет владельца на копирование сохраняется. После таймаута копирования PNG обнови Figma и заново открой подключение.
